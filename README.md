# Video Landing Page

Kleine, responsive GitHub-Pages-Webseite für vier Videos.

## Struktur

- `index.html` – Landing Page
- `templates/video1.html` bis `video4.html` – einzelne Videoseiten
- `videos/video1.mp4` bis `video4.mp4` – hier deine echten Videos ablegen
- `css/styles.css` – komplettes Styling
- `js/script.js` – kleine JavaScript-Funktionen

## Videos ersetzen

Die vier leeren `.mp4`-Dateien sind nur Platzhalter. Ersetze sie durch deine eigenen Videos und behalte die Dateinamen:

- `video1.mp4`
- `video2.mp4`
- `video3.mp4`
- `video4.mp4`

## Texte ändern

Die Titel und Beschreibungen kannst du direkt in `index.html` und den Dateien unter `templates/` ändern.

## GitHub Pages

Lade den Inhalt dieses Ordners in dein Repository. Stelle anschließend unter
`Settings → Pages` deine gewünschte Branch/Folder-Kombination für GitHub Pages ein.

Die Seite startet mit `index.html`.
